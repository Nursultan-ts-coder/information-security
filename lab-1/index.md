# Information Security Course - Laboratory Work

## Development Environment

This laboratory work was completed using **Jupyter Notebook** as the primary development and documentation environment.

## Overview

This lab is part of the Information Security course curriculum at the university. The interactive nature of Jupyter Notebook allows for step-by-step execution and visualization of security concepts, making it an ideal platform for educational purposes in information security.

## Tools Used

- **Jupyter Notebook**: Interactive computing environment for developing and presenting the laboratory exercises
