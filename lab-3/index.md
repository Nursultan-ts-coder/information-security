# Lab 3 — Notebook Tasks (VS Code)

This lab contains a single notebook with shell-based tasks. Run it directly in VS Code using the Jupyter extension.

## Contents

- `task.ipynb` — the notebook with step-by-step tasks

## Quick Start (VS Code)

1. Open the folder `labs/lab-3/` in VS Code.
2. Command Palette → “Python: Select Interpreter” → pick `labs/jupyter-env/bin/python`.
3. Open `task.ipynb` and select the matching kernel.
4. Run cells with the Run button or “Run All”.
