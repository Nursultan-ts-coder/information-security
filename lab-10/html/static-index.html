🌐 NGINX Static Site Demo

This page is served directly by NGINX without any backend.

Configuration Used:

01-static-site.conf

Port: 8001

Root: /var/www/html/static-demo

What's happening:

  • NGINX receives your request on port 8001
  • Looks for files in /var/www/html/static-demo
  • Serves this index.html directly
  • No backend server involved
